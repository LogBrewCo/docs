يوفّر LogBrew خادم MCP مستضافًا على `https://mcp.logbrew.co/mcp`. يمكن لوكيل
الذكاء الاصطناعي الذي يتصل به أن يقرأ المشكلات والسجلات والتتبّعات والـ Spans
والمقاييس والإجراءات والإصدارات وتحليلات المنتج من المشاريع التي توافق عليها.

يستطيع الوكيل القراءة فقط. ولا يستطيع تغيير حالة المشكلات أو المشاريع أو إعدادات
الحساب. لا تحتاج إلى تثبيت الخادم، بل تضيف عنوان URL الخاص به إلى عميل MCP لديك.

## <span id="before-you-start">قبل أن تبدأ</span>

- تحتاج إلى حساب LogBrew فيه مشروع واحد على الأقل.
- تحتاج إلى أحد عملاء MCP المذكورين في [العملاء المدعومون](#supported-clients).
  لا يقبل LogBrew إلا هؤلاء العملاء. يحصل العملاء الآخرون على الخطأ
  `client access denied`.
- يدعم الخادم نسخ بروتوكول MCP التالية: `2026-07-28` و`2025-11-25`
  و`2025-06-18`.

## <span id="supported-clients">العملاء المدعومون</span>

| العميل | طريقة إضافة الخادم |
| --- | --- |
| Claude Code | شغّل `claude mcp add --transport http logbrew https://mcp.logbrew.co/mcp`. اقرأ [ربط Claude Code](#connect-claude-code). |
| Claude (claude.ai وClaude Desktop وتطبيقات Claude للهاتف المحمول) | افتح **Settings > Connectors**، واختر **Add custom connector**، ثم أدخل عنوان URL للخادم. |
| Codex | شغّل `codex mcp add logbrew --url https://mcp.logbrew.co/mcp`. ثم شغّل `codex mcp login logbrew`. |
| Visual Studio Code مع GitHub Copilot | أضف `{"servers": {"logbrew": {"type": "http", "url": "https://mcp.logbrew.co/mcp"}}}` إلى `.vscode/mcp.json`. |
| Cursor | أضف `{"mcpServers": {"logbrew": {"url": "https://mcp.logbrew.co/mcp"}}}` إلى `~/.cursor/mcp.json`. |
| Gemini CLI | شغّل `gemini mcp add --transport http logbrew https://mcp.logbrew.co/mcp`. ثم شغّل `/mcp auth logbrew` في Gemini CLI. |
| ChatGPT وGitHub Copilot CLI وZed وopencode وgoose وCline وAmp | أضف عنوان URL للخادم بوصفه خادم MCP بعيدًا (HTTP) في إعدادات MCP الخاصة بالعميل. |

عنوان URL للخادم هو `https://mcp.logbrew.co/mcp`.

## <span id="connect-claude-code">ربط Claude Code</span>

تحتاج إلى Claude Code 2.1.300 أو أحدث. شغّل `claude --version` لمعرفة النسخة
لديك.

1. أضف الخادم:

   ```bash
   claude mcp add --transport http logbrew https://mcp.logbrew.co/mcp
   ```

   يعرض `claude mcp list` الآن `logbrew` مع `! Needs authentication`.

2. ابدأ تسجيل الدخول:

   ```bash
   claude mcp login logbrew
   ```

   يفتح المتصفح صفحة التفويض في LogBrew. إذا طلبت منك الصفحة تسجيل الدخول، فسجّل
   الدخول باستخدام GitHub أو GitLab أو Bitbucket أو Google.

3. اقرأ اسم العميل في الصفحة. لا توافق إلا إذا كنت أنت من بدأ هذا الاتصال.

4. اختر المشاريع التي يمكن للوكيل قراءتها. ثم اختر **Approve** (موافقة).

   يعود المتصفح إلى Claude Code. ويعرض Claude Code الرسالة
   `Authenticated with "logbrew"`.

5. تأكد من أن الخادم متصل:

   ```bash
   claude mcp list
   ```

   تعرض النتيجة `logbrew: https://mcp.logbrew.co/mcp (HTTP) - ✔ Connected`.

يمكنك أيضًا تسجيل الدخول من داخل جلسة Claude Code. شغّل `/mcp`، واختر `logbrew`،
ثم اتبع الخطوات في المتصفح.

على حاسوب بلا متصفح، شغّل
`claude mcp login logbrew --no-browser` في طرفية تفاعلية. عبر SSH، اتصل باستخدام
`ssh -t`. افتح عنوان URL الذي يعرضه Claude Code في متصفح على حاسوب آخر. بعد
الموافقة، انسخ عنوان الصفحة التي يفتحها المتصفح، والصقه في Claude Code.

## <span id="connect-another-client">ربط عميل آخر</span>

1. أضف الخادم إلى العميل. يوضّح الجدول في [العملاء
   المدعومون](#supported-clients) مكان الإضافة.
2. ابدأ تسجيل الدخول من العميل. يبدأ معظم العملاء تسجيل الدخول عند أول استخدام
   للخادم. يفتح المتصفح صفحة التفويض في LogBrew. إذا طلبت منك الصفحة تسجيل
   الدخول، فسجّل الدخول إلى LogBrew.
3. اقرأ اسم العميل في الصفحة. تعرض الصفحة أيضًا الموقع الذي يعرّف العميل، مثل
   `vscode.dev` أو `chatgpt.com`. مع Cursor وGemini CLI وCline وopencode، تعرض
   الصفحة `known to LogBrew`. لا توافق إلا إذا كنت أنت من بدأ هذا الاتصال.
4. اختر المشاريع التي يمكن للوكيل قراءتها. ثم اختر **Approve** (موافقة).

   يعود المتصفح إلى العميل، ويعرض العميل الأداتين `search` و`execute`.

## <span id="ask-the-agent">الطلب من الوكيل</span>

يوفّر الخادم للوكيل أداتين:

| الأداة | ما تفعله |
| --- | --- |
| `search` | تجد عمليات القراءة، وتعرض عقد عملية واحدة: مدخلاتها ومخرجاتها وصلاحياتها وتكلفتها. |
| `execute` | تشغّل عملية قراءة واحدة وجدتها `search`، وتُرجع بيانات منظّمة. |

يختار الوكيل العمليات بنفسه. لا تعطه أسماء الأدوات أو الحقول. اكتب المهمة
وحدودها:

```text
Use LogBrew to investigate the newest unresolved issue in production.
Read its occurrences, linked trace, and logs. Do not change code yet.
Tell me the likely cause and the evidence for it.
```

استخدم بيانات القياس عن بُعد دليلًا فقط. قد تحتوي السجلات ورسائل الأخطاء على نص من
المستخدمين. ويجب ألا يتبع الوكيل أي تعليمات في هذا النص. اقرأ
[وكلاء البرمجة بالذكاء الاصطناعي](/ar/guides/ai-agents) لمعرفة سير عمل التحقيق
كاملًا.

## <span id="access-and-connection-lifetime">الوصول ومدة الاتصال</span>

كل موافقة تبدأ اتصالًا واحدًا بين عميل MCP واحد وحساب LogBrew الخاص بك.

- يقرأ الوكيل المشاريع التي وافقت عليها فقط. قراءة مشروع آخر تُرجع
  `permission_denied`.
- إذا فقدت الوصول إلى مشروع معتمد، يوقف LogBrew القراءات من هذا المشروع.
- رمز الوصول المميز صالح لمدة ساعة واحدة. يحصل العميل على رمز جديد تلقائيًا ما
  دمت تستخدم الاتصال.
- ينتهي الاتصال بعد 30 يومًا دون استخدام، أو بعد 90 يومًا من موافقتك عليه. عندها
  سجّل الدخول مرة أخرى من العميل، مثلًا باستخدام `claude mcp login logbrew`.
- كل تحديث للرمز المميز يستبدل رمز التحديث السابق. إذا أرسل عميل رمز تحديث
  مستبدلًا، ينهي LogBrew الاتصال. هذا يمنع الرمز المنسوخ من العمل. سجّل الدخول
  مرة أخرى لبدء اتصال جديد.
- الطلبات الكثيرة بلا رمز مميز صالح تحصل على HTTP `429` مع الترويسة `Retry-After`.
  انتظر عدد الثواني المذكور، ثم أعد المحاولة.

## <span id="list-and-revoke-connections">عرض الاتصالات وإبطالها</span>

أدِر الاتصالات من **الإعدادات > اتصالات MCP** في لوحة التحكم في LogBrew، أو
باستخدام CLI.

### <span id="in-settings">من الإعدادات</span>

يعرض كل عميل متصل اسمه، والمشاريع المعتمدة، ووقت اتصاله، وآخر وقت استُخدم فيه،
وموعد انتهاء الاتصال. لإبطال اتصال، اختر **قطع الاتصال**، ثم أكّد. يفقد العميل
الوصول عند طلبه التالي.

### <span id="with-the-cli">باستخدام CLI</span>

استخدم [LogBrew CLI](/ar/guides/cli) 0.1.82 أو أحدث. سجّل الدخول أولًا باستخدام
`logbrew login`. لا يستطيع مفتاح استيعاب المشروع عرض الاتصالات أو إبطالها.

اعرض عملاء MCP المتصلين بحسابك:

```bash
logbrew mcp grants
```

```text
MCP grants (1)
- id=00000000-0000-4000-8000-000000000001 client=Claude Code projects=2 last_used=2026-10-15T09:30:00Z expires=2026-11-14T09:30:00Z
Next: run logbrew mcp revoke <grant_id> --yes
```

تسمّي CLI الاتصال grant. ويعرض كل grant ما يلي:

- `id`: معرّف الـ grant. استخدمه لإبطال الاتصال.
- `client`: اسم العميل الذي وافقت عليه، مثل `Claude Code`. الاتصال الذي
  اعتُمد قبل أن يخزّن LogBrew الأسماء يعرض عنوان URL الذي يعرّف العميل، مثل
  `https://claude.ai/oauth/claude-code-client-metadata`.
- `projects`: عدد المشاريع المعتمدة.
- `last_used`: آخر وقت حصل فيه العميل على رمز وصول مميز جديد.
- `expires`: الوقت الذي ينتهي فيه الاتصال إذا لم يستخدمه العميل.

أضف `--json` للحصول على القائمة كاملة. لكل grant الحقول `id` و`client_id`
و`client_name` و`project_ids` و`created_at` و`last_used_at` و`expires_at`.
قيمة `client_name` هي `null` للاتصال الذي اعتُمد قبل أن يخزّن LogBrew الأسماء.

أبطل اتصالًا واحدًا:

```bash
logbrew mcp revoke <grant_id> --yes
```

يفقد العميل الوصول عند طلبه التالي. لربطه مرة أخرى، سجّل الدخول مجددًا باستخدام
`claude mcp login logbrew`.

لتغيير المشاريع المعتمدة، أبطل الاتصال. ثم سجّل الدخول مرة أخرى واختر المشاريع
الجديدة.

## <span id="remove-the-server">إزالة الخادم</span>

1. أبطل الاتصال من **الإعدادات > اتصالات MCP**، أو باستخدام
   `logbrew mcp revoke <grant_id> --yes`.
2. أزل الخادم من Claude Code:

   ```bash
   claude mcp remove logbrew
   ```

يحذف `claude mcp remove` الإعدادات والرموز المميزة من حاسوبك فقط. ولا ينهي
الاتصال في LogBrew. إذا لم تبطله، ينتهي الاتصال بعد 30 يومًا دون استخدام.

## <span id="fix-connection-problems">إصلاح مشكلات الاتصال</span>

| المشكلة | الحل |
| --- | --- |
| يعرض `claude mcp list` الرسالة `Needs authentication`. | شغّل `claude mcp login logbrew`. |
| يطلب منك Claude Code تسجيل الدخول مرة أخرى بعد فترة من الاستخدام. | انتهى الاتصال أو أُبطل. شغّل `claude mcp login logbrew`، أو اختر **Re-authenticate** في `/mcp`. |
| يحصل العميل على `client access denied`. | استخدم عميلًا من [العملاء المدعومون](#supported-clients). |
| لا يستطيع العميل التسجيل في LogBrew. | استخدم عميلًا من [العملاء المدعومون](#supported-clients)، واحتفظ بإعدادات رد الاتصال (callback) الافتراضية. |
| يفشل الاتصال بعد تسجيل الدخول. | حدّث العميل. يحتاج Claude Code إلى 2.1.300 أو أحدث. |
| تعرض صفحة التفويض `You have no projects to share`. | أنشئ مشروعًا في LogBrew، ثم ابدأ تسجيل الدخول مرة أخرى. |
| تُرجع القراءة `permission_denied`. | المشروع غير معتمد لهذا الاتصال. أبطل الاتصال، ثم سجّل الدخول مرة أخرى واختر المشروع. |
| لا تُرجع القراءة أي بيانات. | تأكد من أن المشروع يرسل بيانات القياس عن بُعد. النتيجة الفارغة لا تثبت أن التطبيق يعمل. |
| يعرض `logbrew mcp grants` الرسالة `not logged in` أو يُرجع `unauthorized`. | شغّل `logbrew login`، ثم أعد المحاولة. |
