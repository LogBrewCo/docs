LogBrew memiliki server MCP yang di-host di `https://mcp.logbrew.co/mcp`. Agen
AI yang terhubung ke server ini dapat membaca masalah, log, trace, span,
metrik, aksi, rilis, dan analitik produk dari proyek yang Anda setujui.

Agen hanya dapat membaca. Agen tidak dapat mengubah status masalah, proyek,
atau pengaturan akun. Anda tidak perlu menginstal server. Tambahkan URL-nya ke
klien MCP Anda.

## Sebelum memulai

- Anda memerlukan akun LogBrew dengan minimal 1 proyek.
- Anda memerlukan Claude Code 2.1.300 atau yang lebih baru. Server hanya
  mendukung protokol MCP versi `2026-07-28`. Jalankan `claude --version` untuk
  melihat versi Anda.
- LogBrew hanya menerima klien MCP yang disetujui. Saat ini, Claude Code
  adalah satu-satunya klien yang disetujui. Klien lain mendapat error
  `client access denied`.

## Hubungkan Claude Code

1. Tambahkan server:

   ```bash
   claude mcp add --transport http logbrew https://mcp.logbrew.co/mcp
   ```

   `claude mcp list` kini menampilkan `logbrew` dengan `! Needs authentication`.

2. Mulai proses masuk:

   ```bash
   claude mcp login logbrew
   ```

   Browser Anda membuka halaman otorisasi LogBrew. Jika halaman meminta Anda
   masuk, masuk dengan GitHub, GitLab, atau Bitbucket.

3. Baca nama klien di halaman itu. Setujui hanya jika Anda sendiri yang
   memulai koneksi ini.

4. Pilih proyek yang dapat dibaca agen. Lalu pilih **Setujui**.

   Browser kembali ke Claude Code. Claude Code menampilkan
   `Authenticated with "logbrew"`.

5. Pastikan server sudah terhubung:

   ```bash
   claude mcp list
   ```

   Hasilnya menampilkan `logbrew: https://mcp.logbrew.co/mcp (HTTP) - ✔ Connected`.

Anda juga dapat masuk dari sesi Claude Code. Jalankan `/mcp`, pilih
`logbrew`, lalu ikuti langkahnya di browser.

Di komputer tanpa browser, jalankan
`claude mcp login logbrew --no-browser` di terminal interaktif. Melalui SSH,
hubungkan dengan `ssh -t`. Buka URL yang ditampilkan Claude Code di browser
pada komputer lain. Setelah menyetujui, salin alamat halaman yang dibuka
browser. Tempelkan alamat itu ke Claude Code.

## Beri tugas ke agen

Server memberikan 2 tool kepada agen:

| Tool | Fungsi |
| --- | --- |
| `search` | Mencari operasi baca dan menampilkan kontrak satu operasi: input, output, izin, dan biayanya. |
| `execute` | Menjalankan satu operasi baca yang ditemukan `search`, lalu mengembalikan data terstruktur. |

Agen memilih operasinya sendiri. Anda tidak perlu memberikan nama tool atau
kolom. Tulis tugas dan batasannya:

```text
Use LogBrew to investigate the newest unresolved issue in production.
Read its occurrences, linked trace, and logs. Do not change code yet.
Tell me the likely cause and the evidence for it.
```

Gunakan telemetri hanya sebagai bukti. Log dan pesan error dapat berisi teks
dari pengguna. Agen tidak boleh mengikuti instruksi di dalam teks itu. Baca
[Agen coding AI](/id/guides/ai-agents) untuk alur kerja investigasi
yang lengkap.

## Akses dan masa berlaku koneksi

Setiap persetujuan memulai 1 koneksi antara 1 klien MCP dan akun LogBrew Anda.

- Agen hanya membaca proyek yang Anda setujui. Pembacaan proyek lain
  mengembalikan `permission_denied`.
- Jika Anda kehilangan akses ke proyek yang disetujui, LogBrew menghentikan
  pembacaan proyek tersebut.
- Token akses berlaku selama 1 jam. Claude Code mendapatkan token baru secara
  otomatis selama Anda memakai koneksi.
- Koneksi berakhir setelah 30 hari tidak dipakai, atau 90 hari setelah Anda
  menyetujuinya. Setelah itu, masuk lagi dengan `claude mcp login logbrew`.
- Setiap kali token diperbarui, refresh token sebelumnya diganti. Jika klien
  mengirim refresh token yang sudah diganti, LogBrew mengakhiri koneksi. Ini
  mencegah token hasil salinan bekerja. Masuk lagi untuk memulai koneksi baru.
- Terlalu banyak permintaan tanpa token yang valid mendapat HTTP `429` dengan
  header `Retry-After`. Tunggu selama jumlah detik itu, lalu coba lagi.

## Tampilkan dan cabut koneksi

Kelola koneksi di **Pengaturan > Koneksi MCP** pada dasbor LogBrew, atau
dengan CLI.

### Di Pengaturan

Setiap klien yang terhubung menampilkan nama, proyek yang disetujui, waktu
terhubung, waktu terakhir dipakai, dan waktu koneksi berakhir. Untuk mencabut
koneksi, pilih **Putuskan**, lalu konfirmasi. Klien kehilangan akses pada
permintaan berikutnya.

### Dengan CLI

Gunakan [LogBrew CLI](/id/guides/cli) 0.1.82 atau yang lebih baru. Masuk
terlebih dahulu dengan `logbrew login`. Kunci ingest proyek tidak dapat
menampilkan atau mencabut koneksi.

Tampilkan daftar klien MCP yang terhubung ke akun Anda:

```bash
logbrew mcp grants
```

```text
MCP grants (1)
- id=00000000-0000-4000-8000-000000000001 client=Claude Code projects=2 last_used=2026-10-15T09:30:00Z expires=2026-11-14T09:30:00Z
Next: run logbrew mcp revoke <grant_id> --yes
```

CLI menyebut koneksi sebagai “grant”. Setiap grant menampilkan:

- `id`: ID grant. Gunakan ID ini untuk mencabut koneksi.
- `client`: nama klien yang Anda setujui, misalnya `Claude Code`. Koneksi yang
  disetujui sebelum LogBrew menyimpan nama klien menampilkan URL yang
  mengidentifikasi klien, misalnya
  `https://claude.ai/oauth/claude-code-client-metadata`.
- `projects`: jumlah proyek yang disetujui.
- `last_used`: waktu terakhir klien mendapatkan token akses baru.
- `expires`: waktu koneksi berakhir jika klien tidak memakainya.

Tambahkan `--json` untuk mendapatkan daftar lengkap. Setiap grant berisi
`id`, `client_id`, `client_name`, `project_ids`, `created_at`,
`last_used_at`, dan `expires_at`. `client_name` bernilai `null` untuk koneksi
yang disetujui sebelum LogBrew menyimpan nama klien.

Cabut 1 koneksi:

```bash
logbrew mcp revoke <grant_id> --yes
```

Klien kehilangan akses pada permintaan berikutnya. Untuk menghubungkannya
kembali, masuk lagi dengan `claude mcp login logbrew`.

Untuk mengubah proyek yang disetujui, cabut koneksinya. Lalu masuk lagi dan
pilih proyek yang baru.

## Hapus server

1. Cabut koneksi di **Pengaturan > Koneksi MCP**, atau dengan
   `logbrew mcp revoke <grant_id> --yes`.
2. Hapus server dari Claude Code:

   ```bash
   claude mcp remove logbrew
   ```

`claude mcp remove` hanya menghapus konfigurasi dan token di komputer Anda.
Perintah ini tidak mengakhiri koneksi di LogBrew. Jika Anda tidak
mencabutnya, koneksi berakhir setelah 30 hari tidak dipakai.

## <span id="fix-connection-problems">Atasi kendala koneksi</span>

| Kendala | Solusi |
| --- | --- |
| `claude mcp list` menampilkan `Needs authentication`. | Jalankan `claude mcp login logbrew`. |
| Claude Code meminta Anda masuk lagi setelah beberapa waktu dipakai. | Koneksi sudah berakhir atau dicabut. Jalankan `claude mcp login logbrew`, atau pilih **Re-authenticate** di `/mcp`. |
| Klien mendapat `client access denied`. | Gunakan klien yang disetujui. Saat ini, hanya Claude Code yang disetujui. |
| Koneksi gagal setelah masuk. | Perbarui Claude Code ke 2.1.300 atau yang lebih baru. |
| Halaman otorisasi menampilkan `You have no projects to share`. | Buat proyek di LogBrew, lalu mulai proses masuk lagi. |
| Pembacaan mengembalikan `permission_denied`. | Proyek ini tidak disetujui untuk koneksi ini. Cabut koneksi, lalu masuk lagi dan pilih proyek tersebut. |
| Pembacaan tidak mengembalikan data. | Pastikan proyek mengirim telemetri. Hasil kosong tidak membuktikan bahwa aplikasi berjalan baik. |
| `logbrew mcp grants` menampilkan `not logged in` atau mengembalikan `unauthorized`. | Jalankan `logbrew login`, lalu coba lagi. |
