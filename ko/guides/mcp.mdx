title: "MCP로 AI 에이전트 연결하기"
description: "Claude Code, Claude, VS Code, Cursor, Codex, ChatGPT 또는 다른 MCP 클라이언트를 LogBrew 호스팅 MCP 서버에 연결하고, 읽을 수 있는 프로젝트를 승인하세요. 연결은 설정이나 CLI에서 관리합니다."
---

LogBrew는 `https://mcp.logbrew.co/mcp`에서 호스팅 MCP 서버를 운영합니다. 이 서버에 연결한 AI 에이전트는 승인한 프로젝트의 이슈, 로그, 트레이스, 스팬, 메트릭, 액션, 릴리스, 제품 분석 데이터를 읽을 수 있습니다.

에이전트는 읽기만 할 수 있습니다. 이슈 상태, 프로젝트, 계정 설정은 바꿀 수 없습니다. 서버를 설치할 필요는 없습니다. MCP 클라이언트에 서버 URL을 추가하면 됩니다.

## 시작하기 전에

- 프로젝트가 1개 이상 있는 LogBrew 계정이 필요합니다.
- [지원 클라이언트](#supported-clients) 목록에 있는 MCP 클라이언트가 필요합니다. LogBrew는 이 클라이언트만 받습니다. 다른 클라이언트는 `client access denied` 오류를 받습니다.
- 서버는 MCP 프로토콜 버전 `2026-07-28`, `2025-11-25`, `2025-06-18`을 지원합니다.

## <span id="supported-clients">지원 클라이언트</span>

| 클라이언트 | 서버 추가 방법 |
| --- | --- |
| Claude Code | `claude mcp add --transport http logbrew https://mcp.logbrew.co/mcp`를 실행하세요. [Claude Code 연결하기](#connect-claude-code)를 참고하세요. |
| Claude(claude.ai, Claude Desktop, Claude 모바일 앱) | **Settings > Connectors**를 열고 **Add custom connector**를 선택한 뒤 서버 URL을 입력하세요. |
| Codex | `codex mcp add logbrew --url https://mcp.logbrew.co/mcp`를 실행하세요. 그다음 `codex mcp login logbrew`를 실행하세요. |
| Visual Studio Code와 GitHub Copilot | `.vscode/mcp.json`에 `{"servers": {"logbrew": {"type": "http", "url": "https://mcp.logbrew.co/mcp"}}}`를 추가하세요. |
| Cursor | `~/.cursor/mcp.json`에 `{"mcpServers": {"logbrew": {"url": "https://mcp.logbrew.co/mcp"}}}`를 추가하세요. |
| Gemini CLI | `gemini mcp add --transport http logbrew https://mcp.logbrew.co/mcp`를 실행하세요. 그다음 Gemini CLI에서 `/mcp auth logbrew`를 실행하세요. |
| ChatGPT, GitHub Copilot CLI, Zed, opencode, goose, Cline, Amp | 클라이언트의 MCP 설정에서 서버 URL을 원격(HTTP) MCP 서버로 추가하세요. |

서버 URL은 `https://mcp.logbrew.co/mcp`입니다.

## <span id="connect-claude-code">Claude Code 연결하기</span>

Claude Code 2.1.300 이상이 필요합니다. 버전을 확인하려면 `claude --version`을 실행하세요.

1. 서버를 추가하세요.

   ```bash
   claude mcp add --transport http logbrew https://mcp.logbrew.co/mcp
   ```

   이제 `claude mcp list`에 `logbrew`가 `! Needs authentication`과 함께 나타납니다.

2. 로그인을 시작하세요.

   ```bash
   claude mcp login logbrew
   ```

   브라우저에 LogBrew 승인 페이지가 열립니다. 로그인하라는 화면이 나오면 GitHub, GitLab, Bitbucket, Google 중 하나로 로그인하세요.

3. 페이지에서 클라이언트 이름을 확인하세요. 직접 시작한 연결일 때만 승인하세요.

4. 에이전트가 읽을 수 있는 프로젝트를 선택하세요. 그다음 **Approve**를 선택하세요.

   브라우저가 Claude Code로 돌아갑니다. Claude Code에 `Authenticated with "logbrew"`가 표시됩니다.

5. 서버가 연결되었는지 확인하세요.

   ```bash
   claude mcp list
   ```

   결과에 `logbrew: https://mcp.logbrew.co/mcp (HTTP) - ✔ Connected`가 표시됩니다.

Claude Code 세션 안에서도 로그인할 수 있습니다. `/mcp`를 실행하고 `logbrew`를 선택한 뒤 브라우저에 나오는 단계를 따르세요.

브라우저가 없는 컴퓨터에서는 대화형 터미널에서 `claude mcp login logbrew --no-browser`를 실행하세요. SSH로 접속한다면 `ssh -t`로 연결하세요. Claude Code가 보여 주는 URL을 다른 컴퓨터의 브라우저에서 여세요. 승인한 뒤 브라우저가 연 페이지의 주소를 복사하세요. 그 주소를 Claude Code에 붙여 넣으세요.

## 다른 클라이언트 연결하기

1. 클라이언트에 서버를 추가하세요. 추가할 위치는 [지원 클라이언트](#supported-clients) 표에 나와 있습니다.
2. 클라이언트에서 로그인을 시작하세요. 대부분의 클라이언트는 서버를 처음 사용할 때 로그인을 시작합니다. 브라우저에 LogBrew 승인 페이지가 열립니다. 로그인하라는 화면이 나오면 LogBrew에 로그인하세요.
3. 페이지에서 클라이언트 이름을 확인하세요. 페이지에는 클라이언트를 식별하는 웹사이트도 표시됩니다(예: `vscode.dev`, `chatgpt.com`). Cursor, Gemini CLI, Cline, opencode는 `known to LogBrew`로 표시됩니다. 직접 시작한 연결일 때만 승인하세요.
4. 에이전트가 읽을 수 있는 프로젝트를 선택하세요. 그다음 **Approve**를 선택하세요.

   브라우저가 클라이언트로 돌아가고, 클라이언트에 `search` 도구와 `execute` 도구가 표시됩니다.

## 에이전트에게 요청하기

서버는 에이전트에게 도구 2개를 제공합니다.

| 도구 | 하는 일 |
| --- | --- |
| `search` | 읽기 작업을 찾고, 작업 1개의 계약을 보여 줍니다. 입력, 출력, 권한, 비용이 들어 있습니다. |
| `execute` | `search`로 찾은 읽기 작업 1개를 실행하고 구조화된 데이터를 반환합니다. |

작업은 에이전트가 고릅니다. 도구 이름이나 필드를 알려 줄 필요는 없습니다. 할 일과 제한을 적으세요.

```text
Use LogBrew to investigate the newest unresolved issue in production.
Read its occurrences, linked trace, and logs. Do not change code yet.
Tell me the likely cause and the evidence for it.
```

텔레메트리는 근거로만 사용하세요. 로그와 오류 메시지에는 사용자가 입력한 텍스트가 들어 있을 수 있습니다. 에이전트는 그 텍스트에 있는 지시를 따르면 안 됩니다. 전체 조사 워크플로는 [AI 코딩 에이전트](/ko/guides/ai-agents)를 읽으세요.

## 접근 권한과 연결 유효 기간

승인할 때마다 MCP 클라이언트 1개와 LogBrew 계정 사이에 연결이 1개 만들어집니다.

- 에이전트는 승인한 프로젝트만 읽습니다. 다른 프로젝트를 읽으면 `permission_denied`가 반환됩니다.
- 승인한 프로젝트에 대한 접근 권한을 잃으면 LogBrew가 그 프로젝트의 조회를 막습니다.
- 액세스 토큰은 1시간 동안 유효합니다. 연결을 사용하는 동안 클라이언트가 새 토큰을 자동으로 받습니다.
- 연결은 30일 동안 사용하지 않거나 승인 후 90일이 지나면 끝납니다. 그러면 클라이언트에서 다시 로그인하세요(예: `claude mcp login logbrew`).
- 토큰을 갱신할 때마다 이전 갱신 토큰이 교체됩니다. 클라이언트가 교체된 갱신 토큰을 보내면 LogBrew는 연결을 끝냅니다. 이렇게 해서 복사된 토큰이 작동하지 못하게 막습니다. 새 연결을 시작하려면 다시 로그인하세요.
- 유효한 토큰 없이 요청을 너무 많이 보내면 HTTP `429`와 `Retry-After` 헤더를 받습니다. 헤더에 적힌 초만큼 기다린 뒤 다시 시도하세요.

## 연결 목록 확인 및 해지하기

연결은 LogBrew 대시보드의 **설정 > MCP 연결**이나 CLI에서 관리하세요.

### 설정에서

연결된 각 클라이언트의 이름, 승인된 프로젝트, 연결 시각, 마지막 사용 시각, 연결 종료 시각이 표시됩니다. 연결을 해지하려면 **연결 해제**를 선택하고 확인하세요. 클라이언트는 다음 요청부터 접근할 수 없습니다.

### CLI에서

[LogBrew CLI](/ko/guides/cli) 0.1.82 이상을 사용하세요. 먼저 `logbrew login`으로 로그인하세요. 프로젝트 수집 키로는 연결 목록을 보거나 연결을 해지할 수 없습니다.

계정에 연결된 MCP 클라이언트 목록을 확인하세요.

```bash
logbrew mcp grants
```

```text
MCP grants (1)
- id=00000000-0000-4000-8000-000000000001 client=Claude Code projects=2 last_used=2026-10-15T09:30:00Z expires=2026-11-14T09:30:00Z
Next: run logbrew mcp revoke <grant_id> --yes
```

CLI는 연결을 grant라고 부릅니다. 각 grant에는 다음이 표시됩니다.

- `id`: grant ID입니다. 연결을 해지할 때 사용하세요.
- `client`: 승인한 클라이언트 이름입니다. 예를 들면 `Claude Code`입니다. LogBrew가 이름을 저장하기 전에 승인한 연결에는 클라이언트를 식별하는 URL이 표시됩니다. 예를 들면 `https://claude.ai/oauth/claude-code-client-metadata`입니다.
- `projects`: 승인된 프로젝트 수입니다.
- `last_used`: 클라이언트가 마지막으로 새 액세스 토큰을 받은 시각입니다.
- `expires`: 클라이언트가 연결을 사용하지 않을 때 연결이 끝나는 시각입니다.

전체 목록을 받으려면 `--json`을 추가하세요. 각 grant에는 `id`, `client_id`, `client_name`, `project_ids`, `created_at`, `last_used_at`, `expires_at`이 있습니다. LogBrew가 이름을 저장하기 전에 승인한 연결의 `client_name`은 `null`입니다.

연결 1개를 해지하세요.

```bash
logbrew mcp revoke <grant_id> --yes
```

클라이언트는 다음 요청부터 접근할 수 없습니다. 다시 연결하려면 `claude mcp login logbrew`로 다시 로그인하세요.

승인한 프로젝트를 바꾸려면 연결을 해지하세요. 그다음 다시 로그인하고 새 프로젝트를 선택하세요.

## 서버 제거하기

1. **설정 > MCP 연결**에서 연결을 해지하거나 `logbrew mcp revoke <grant_id> --yes`를 실행하세요.
2. Claude Code에서 서버를 제거하세요.

   ```bash
   claude mcp remove logbrew
   ```

`claude mcp remove`는 내 컴퓨터에 있는 설정과 토큰만 삭제합니다. LogBrew의 연결은 끝나지 않습니다. 연결을 해지하지 않으면 30일 동안 사용하지 않은 뒤에 연결이 끝납니다.

## <span id="fix-connection-problems">연결 문제 해결하기</span>

| 문제 | 해결 방법 |
| --- | --- |
| `claude mcp list`에 `Needs authentication`이 표시됩니다. | `claude mcp login logbrew`를 실행하세요. |
| 한동안 사용한 뒤 Claude Code가 다시 로그인하라고 요청합니다. | 연결이 끝났거나 해지되었습니다. `claude mcp login logbrew`를 실행하거나 `/mcp`에서 **Re-authenticate**를 선택하세요. |
| 클라이언트가 `client access denied`를 받습니다. | [지원 클라이언트](#supported-clients)에 있는 클라이언트를 사용하세요. |
| 클라이언트를 LogBrew에 등록할 수 없습니다. | [지원 클라이언트](#supported-clients)에 있는 클라이언트를 사용하고, 기본 콜백 설정을 그대로 두세요. |
| 로그인한 뒤 연결에 실패합니다. | 클라이언트를 업데이트하세요. Claude Code는 2.1.300 이상이 필요합니다. |
| 승인 페이지에 `You have no projects to share`가 표시됩니다. | LogBrew에서 프로젝트를 만든 뒤 로그인을 다시 시작하세요. |
| 조회 결과로 `permission_denied`가 반환됩니다. | 이 연결에 승인되지 않은 프로젝트입니다. 연결을 해지하고 다시 로그인한 뒤 해당 프로젝트를 선택하세요. |
| 조회 결과에 데이터가 없습니다. | 프로젝트가 텔레메트리를 보내는지 확인하세요. 결과가 비어 있다고 해서 앱이 정상이라는 증명은 아닙니다. |
| `logbrew mcp grants`에 `not logged in`이 표시되거나 `unauthorized`가 반환됩니다. | `logbrew login`을 실행한 뒤 다시 시도하세요. |
