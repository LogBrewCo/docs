---
title: "Send your first event"
description: "Create a LogBrew project, send one safe info event, and find it again from the CLI."
---

This task gives you one complete first-run loop: sign in, create a project,
send one native event, and verify it from the terminal.

<Note>
  This page uses the native telemetry API path so the first event is explicit
  and easy to inspect. After it works, use the SDK setup page for your runtime.
</Note>

## Before you start

You need:

- The `logbrew` CLI installed.
- A signed-in LogBrew account.
- One project created from Add Project.
- The project-scoped ingest value shown by Add Project.

Do not use account login values as SDK or ingest configuration. Use the
project-scoped value from the setup panel.

## Sign in

```bash
logbrew login
logbrew status --json
```

If an AI coding agent is helping, it should run only the status check. A human
should complete browser sign-in.

## Create the project

Open Add Project from the website or dashboard:

```text
https://logbrew.co/en/dashboard?view=projects&setup=1
```

Choose the platform that matches your app, create the project, then keep the
setup panel open. Copy the project ID and the project-scoped ingest value into
your local shell environment:

```bash
export LOGBREW_PROJECT_ID="00000000-0000-0000-0000-000000000000"
export LOGBREW_INGEST_BEARER="paste-project-scoped-ingest-value"
```

## Send one info event

Create a small event file:

```json first-event.json
{
  "project_id": "00000000-0000-0000-0000-000000000000",
  "environment": "production",
  "release": "first-event@1",
  "service_name": "checkout-api",
  "sdk_name": "native-api",
  "sdk_version": "0.1.0",
  "items": [
    {
      "type": "log",
      "data": {
        "severity": "info",
        "message": "first LogBrew event",
        "source": "setup",
        "attributes": {
          "guide": "first-event"
        }
      }
    }
  ]
}
```

Replace `project_id` with the project ID from Add Project, then send it:

```bash
curl "$LOGBREW_API_URL/api/telemetry/ingest" \
  -H "Authorization: Bearer $LOGBREW_INGEST_BEARER" \
  -H "Content-Type: application/json" \
  --data @first-event.json
```

A successful response includes accepted item counts, such as one accepted log.

## Find the event

Use the CLI read path so humans and agents see the same result.

```bash
logbrew logs info --json
logbrew read logs --release first-event@1 --environment production --json
```

Look for the `first LogBrew event` message and `severity: "info"`.
